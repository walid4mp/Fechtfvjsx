tikboost.wh Privacy Policy — ready-to-publish files

File: docs/index.html

This folder is prepared for GitHub Pages:
1. Upload the `docs/index.html` file to the root repository path `docs/index.html` on the `main` branch.
2. In GitHub, open the repository Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/docs`, then Save.
5. Wait for GitHub Pages to publish and open the URL GitHub shows. It will usually look like:
   https://walid4mp.github.io/tikboost-full/
   Do not assume the URL is live until GitHub Pages confirms it.
6. Open the page in a private/incognito browser and confirm it loads publicly over HTTPS.
7. Paste the confirmed URL into Google Play Console → App content → Privacy policy.

Before publishing:
- Confirm the support email `ww608352@gmail.com` is correct.
- Review the policy against the exact SDKs and data the released app collects.
- This policy is a starter draft, not legal advice.
